# JOVRA Studio director

Use for JOVRA film production or Studio implementation. A project starts from its actual footage, point-event revision, lessons and chosen story; it does not start from a dramatic claim.

Read the current repository rules and `../../CLAUDE-STUDIO-BRIDGE-PROMPT.md`. Keep the existing tennis app useful on its own. Preserve the five tabs, offline originals and free/local foundation. The Studio archive contains instructions and examples, not an installed service.

Write a project lock with: project ID, source manifest revision/hash, point-event revision, chosen profile/version, output preference, source/participant rights, identity/access mode, quote authorization if applicable, and brand tokens. Use JOVRA, Court Arc, ivory `#F4F1E8`, forest `#092A25`, chartreuse `#D7F56A` and clay `#C47752`. Manufacturer names are user text; no sponsor logos or professional likenesses.

Route only the needed stages:

1. Source preparation or camera alignment: `../jovra-media-ingest-sync/SKILL.md`.
2. Intent, feeling and treatment: `../jovra-storycraft/SKILL.md`.
3. Source-linked executable plan: `../jovra-edit-plan/SKILL.md`.
4. Picture/audio/export checks: `../jovra-render-delivery/SKILL.md`.
5. Optional paid or cloud execution: `../jovra-cloud-production/SKILL.md`.

Use explicit artifacts between stages: source manifest and sync map → keeper/B-roll catalogs → story brief → validated edit list → render evidence → delivered artifact manifest. Do not pass unexplained prose directly to the renderer. Record missing evidence and omit unsupported beats; a one-camera film with human notes is a complete fallback.

Distinguish private draft selection, final content review, charge acceptance and external publication. Do not copy old project approval into a new project. Existing approved editor output remains intact. A personal clip can be linked to a lesson without granting access to all its source footage.

Before reporting success identify what was actually produced: a proposal, checked plan, rendered file, verified film, isolated cloud job or public release. The workflow never upgrades a metric to Validated just because a director liked the film.
