# Render and deliver a JOVRA film

Use the validated EDL, trusted source/sync manifests and a separately authorized local/private job. Resolve source IDs inside the controlled media workspace; never invoke commands/paths returned by a model. Check actual bytes and current revision bindings before processing.

Map allowlisted operations into maintained FFmpeg/Remotion code. Preserve the existing editor’s source-map and approval constraints when reusing it; create new JOVRA compositions/output paths rather than overwriting a documentary. Normalize phone footage before the strict assembler. The supplied handoff helper is not a renderer.

Render to a new temporary artifact with bounded resource/time limits, then verify before atomically exposing it. Source originals remain unchanged. Inspect probe data, full decode, frame count, duration against the planned rational clock, dimensions/aspect, orientation, colour handling, intended audio tracks, missing/repeated boundary frames and audible continuity. A successful process exit is not readiness.

Review the opening, every camera/audio/effect/annotation boundary and the ending, plus representative action at normal speed. Check score/metric provenance, slow-replay labels, caption accuracy, source evidence and privacy. Measure configured audio levels and compare alignment anchors; do not claim “no drift” from a waveform picture. Phone/portrait outputs need their own safe-area/action check.

Deliver a private film file, thumbnail, source/plan/render hashes, event revision, chapters and genuine captions when available. Interactive multi-angle playback retains the project sources and sync map; the MP4 is the chosen flat story. Keep an original-speed keeper and clean effect alternate when requested.

Failures retain evidence and local media; cancellation cannot report completion. Record planned versus measured values. Prepare YouTube copy and format as optional artifacts, but leave publishing to the explicit user/channel action. Label Sample previews and all unsupported or unverified capability states.
