CHAPTER 03

Keep the local core.
Attach the premium engine.

The architecture is already specified well enough to continue. The hard work is implementing and validating the boundaries, not renaming the stack. [E5, E7]

Implemented

Native iOS · local original + event log

Record → save → Library → replay → correct → export. One authoritative store; originals remain local; scores and stats refold after corrections.

Reference → native work

Studio project, sources and deterministic plan

Ingest verified media → sync/calibration → moments → story profile → StoryPlan → validated EDL. Python reference code anchors parity; model output never bypasses validation.

Not operationally demonstrated

Render, verify, download

Local renderer first; optional bounded cloud job later. Verify frame/time coverage, overlays, audio, output integrity and retention before a customer download is called complete.

Independent native clients

Android · Room · Apple Watch / Wear OS

Share schemas, fixtures and acknowledged state. Each platform needs its own capture, lifecycle, pairing, background and hardware evidence.

Preserve

Local-first originals; event-sourced corrections; provenance and unknown states; synthetic Sample labels; directory durability and canonical/CSV contracts; disabled capabilities until validated; accessible native design tokens.

Do not shortcut

Google Drive is an archive adapter, not the database. A schema test is not a phone transport. A StoryPlan is not a rendered film. A green shared CI job is not a hardware or App Store pass.
