# oracle-spec

This is the useful part of an “oracle edit”: a **written plan** before an editor moves pixels.

Not included: World Cup recipes, Luuk’s voice setup, his exact Remotion graph.

## Write `edit.spec.md`
```
TITLE
DURATION TARGET
SPINE (ordered beats)
PROOF on screen for each beat (path from lock / catalog, or "none — skip beat")
HOOK still text (exact strings)
MOTION (8–10s rules)
WAREHOUSE mux (hook then freeze then audio)
CUTDOWNS needed
GAPS Jon must fill
RISKS (overclaim, name-garble, melted type)
```

If a beat has no proof, delete the beat. Empty is better than a generated metaphor of trust.
Jon accepts or amends the spec. Assemble does not start without `SHIP` on the spec.
