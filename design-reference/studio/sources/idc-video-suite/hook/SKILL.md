# hook

One still. One 8–10s motion clip. Theme from `theme.lock.json`.

## Still (16:9)
Void field. One object from the project (gem, not a new mascot).
Typography is printed, exact strings Jon approved.
Listen-alongs: `LISTEN-ALONG · NON-OFFICIAL` bottom left.
No faces, no extra words, no logos that are not in the lock.

## Motion
Image-to-video from that still. Do not redesign the object.
Locked camera, 3% push-in, core pulse once near 6.5s.
Type is a frozen PNG. No crust, no sugar pour, no melted letters.
End on the same composition.

## Vertical
Rerun 9:16 from the still. Do not crop the landscape clip.
