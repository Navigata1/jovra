How a session runs

1. Load the conductor

Point the agent skills path at the repo. The agent reads SKILL.md. It does not post.

2. Ingest the folder

Not one HTML file. The whole tree. Writes project.lock.json. Palette, wordmark, A-roll, B-roll, banned claims.

3. Warehouse or a seat

Say warehouse and the rail runs. Name a seat and only that seat runs. Resume from the last finished file.

4. You upload

YouTube gets the warehouse file. X and Reels get the hook. LinkedIn and Facebook point at YouTube. Whatnot plays the hook live.

The seven seats

SeatReadsWritesJob
ingest-project The workdir project.lock.json Walk HTML, CSS tokens, README, stills/, raw/, broll/, garage-broll/, screen/, audio. Map what exists. Do not invent a palette when tokens or a gem still already live in the tree.
cut lock + A-roll keepers.json Documentary keepers. Spine only. Optional 1.25× once on voice and picture. Listen-along audio is not cut except for name-garble Jon names.
ingest-broll lock + keepers broll.catalog.json Prefer real terminal and shop captures. Generated art last, and only in lock colors.
oracle-spec lock + catalogs edit.spec.md The useful part of an oracle edit: a written plan before pixels move. If a beat has no proof, delete the beat. Assemble waits for SHIP.
hook lock + spec thumb + 8–10s One still. Frozen type. Locked camera, 3% push-in, one core pulse. 9:16 is a rerun from the still, not a crop of the landscape file.
assemble hook + audio WAREHOUSE.mp4 Hook, then freeze the last frame under the full listen or voice master. Speech does not ride the motion. This file does not go to X.
cutdowns warehouse + lock paste-ready posts Storefronts only. Tags live in the X reply with the YouTube URL.
