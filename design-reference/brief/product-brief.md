# JOVRA product brief

**Outcome:** record safely, find the point, understand the evidence, take one useful practice action, and keep ownership of the video.

Audience: adult recreational and club tennis players; an equipment-aware user who also strings rackets. iOS first; Android after the iOS capture path is validated. Tennis is primary. Doubles is a designed mode requiring additional identification/analysis validation.

Reference scope: 20 iOS screens; 4 original logo directions; 10 scored names; top-10 visual shortlist; Claude implementation prompt. No app has been built by this deliverable.

Navigation:
- Home → setup → court framing → recording → saved session → analysis queue.
- Sessions → match → replay → edit point / clip export.
- Insights → shot map / Serve Lab / Stroke Lab → compare → drill → progress.
- Profile → equipment → string history; backup; account and permissions.

Source truth: all displayed match data, photography, string tensions, connected states and processing progress are illustrative. screens.json controls copy/structure. A generated plot is not an analytics dataset. Code must compute figures from events rather than copy raster chart pixels.

A single session has separate states for original video, analysis, user review and archive. Keep video viewable if analysis fails. Keep local capture usable if Drive is disconnected. Maintain editable user tags and score corrections.

The premium experience comes from reliable recording, crisp replay, useful feedback and familiar equipment detail. Visual polish supports those outcomes.
