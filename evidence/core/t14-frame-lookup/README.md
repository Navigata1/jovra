# Exact decoded frame lookup — bounded T14 prerequisite

FramePlayback decodes a still image at an exact frame on a known constant-rate video timeline. The caller supplies a verified rate and frame count. AVFoundation applies track edit lists, and the returned time is normalized to the video start. Transform is applied and requested-time tolerances are zero. A returned decoded presentation time must map to the requested index; mismatches fail explicitly. Out-of-range requests and unsupported clock arithmetic are refused. Cancellation is checked before and after decoding.
